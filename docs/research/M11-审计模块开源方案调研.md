# M11 审计模块开源方案调研

> 日期：2026-08-14  
> 适用周期：模块 11 审计摘要统计接口  
> 结论：本周期不引入第三方审计框架或源码；继续基于 PostgreSQL 审计事实表提供只读查询与摘要统计，后续导出、归档、WORM、告警再随对象存储和运维体系专项推进。

## 2. 对 File Workshop 的约束结论

1. 审计摘要只能来自 `audit_events` 和 `audit_chain_heads`，不能反向生成或修改审计事实。
2. 审计摘要只服务运维、合规和安全观察；原始审计明细仍是追溯依据。
3. 摘要接口必须仅允许 `SYSTEM_ADMIN` 访问，普通用户不能通过统计接口推断敏感操作分布。
4. 时间范围必须显式传入 `dateFrom/dateTo`，避免无界扫描审计分区。
5. 当前不做审计导出、归档、WORM 锚定和告警，因为这些能力依赖对象存储、归档策略或外部告警系统。
