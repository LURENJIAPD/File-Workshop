## 2. 采纳原则

1. `document_versions` 只追加，恢复历史版本必须创建新版本，不修改旧版本。
2. 文件级锁使用服务端生成的一次性明文 `lockToken`，数据库只保存 SHA-256 摘要。
3. 锁必须有过期时间；获取新锁前先把过期的 ACTIVE 锁标记为 `EXPIRED`。
4. `fencingToken` 来自 `document_lock_counters` 单调递增，后续写入必须能用它抵御旧锁持有者覆盖新锁。
5. API 层不暴露对象存储 Key、Bucket 内部布局、锁 Token 摘要或数据库内部约束细节。
6. 所有版本读取、恢复和锁操作仍走统一权限入口；不因前端隐藏按钮而省略服务端授权。
