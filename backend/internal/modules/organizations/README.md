# 模块 03：组织与空间

本模块对应开发设计文档第 6.4 节，负责组织树、组织成员关系、个人/组织/公共空间、容量配额和组织重组计划，不负责计算文件访问权限。

## 已实现能力

- 组织创建、分页查询、资料修改、状态转换和带闭包表的一致性移动；组织树写操作使用 PostgreSQL 事务级咨询锁，移动时校验乐观锁并拒绝循环关系。
- 用户与组织多对多关系、`PRIMARY`/`MEMBER` 类型、任职名称、有效期、状态、单一活动主职约束和安全版本递增。
- 创建组织时在同一事务建立唯一组织空间；支持管理员显式建立个人空间和公共空间，并管理名称、配额、版本化配置及状态。
- 配额预留、消费、释放和过期状态流转；空间计数器使用条件更新，避免并发超卖。
- 组织变更计划的创建、操作编排、校验、审批、取消和 `MOVE_NODE` 同步执行；创建类写请求和添加计划操作支持 `Idempotency-Key`。
- 组织及成员变更在同一 PostgreSQL 事务写入 Outbox，供后续审计和 Worker 模块处理。

## 边界和延期项

- 本模块只维护组织、成员和空间事实。权限继承、管理委派和资源最终授权由模块 04 实现。
- 数据库设计没有定义个人空间默认配额，因此当前通过管理员接口显式提供名称、配额和配置。自动消费 `USER_CREATED` 的投递调度由模块 16 Worker 接入，不能在没有已确认默认配额时自行生成空间参数。
- `MERGE`、`SPLIT`、成员批量迁移和空间内容迁移已经具备版本化计划数据结构；涉及文件事实的执行器在模块 05 和模块 16 具备后接入。当前只有不依赖文件内容的 `MOVE_NODE` 可同步执行。
- SeaweedFS/S3 暂缓不影响本模块；空间在本阶段只建立元数据和容量边界，不读写文件二进制。
- 本模块使用的表、约束和触发器已经存在于首版 Schema，活动主职及查询索引已经由 `00002_user_management_indexes.sql` 补齐，因此本周期不新增空 Migration，也不要求再次导入初始化 SQL。
