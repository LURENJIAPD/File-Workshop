# File Workshop 前端概念设计稿

本目录包含 15 套可离线浏览的前端概念设计。每套设计均包含：

- `login.html`：登录页；
- `home.html`：登录后的文件工作台主页；
- `theme.css`：该方案独立的视觉语言与布局覆盖。

公共页面结构、响应式基础样式和演示交互位于 `shared/`。根目录的 `index.html` 是设计画廊，可同时预览和比较全部方案。

全部 15 套方案都同时提供浅色和深色主题，不将明暗模式作为不同方案。页面右上角可实时切换，选择会保存在浏览器本地；首次打开且尚未选择时跟随操作系统主题。画廊的主题开关会同步切换全部预览。

## 快速查看

直接打开 `index.html` 即可浏览。为了获得最稳定的浏览器行为，也可以在本目录启动任意静态服务器：

```text
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 交互说明

这是设计验证稿，不连接真实后端。已包含以下演示交互：

- 登录提交与密码显隐；
- 登录页/主页相互跳转；
- 文件名搜索过滤；
- 上传面板和模拟上传进度；
- 侧栏折叠、通知、快捷操作和轻量提示；
- 全部方案的浅色/深色实时切换、系统主题跟随和本地记忆；
- 移动端基础适配。

## 选型后的使用建议

选定方案后，以对应 `theme.css` 为视觉基线，保留 `shared/base.css` 中的可访问性、响应式和通用组件约束，并将 `shared/modes.css` 中该方案的双主题令牌迁移到正式设计令牌系统。正式开发时应将页面结构迁移为 Vue 组件，并使用 OpenAPI 生成的类型替换演示数据。
